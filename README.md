# 动物繁殖系统模组 (Breeding)

为 Survivalcraft 2 (2.4.0.0) 加入动物繁殖系统的独立模组。

当前版本支持 **39 个物种** 的繁殖（参数独立配置，完整生物清单详见 [SPECIES.md 生物图鉴](SPECIES.md)）：

| 类别 | 物种 | 特点 |
|------|------|------|
| 掠食者 | 灰狼 / 郊狼 / 鬣狗 | 冬/春季发情，群居，无需喂食 |
| 大型猫科 | 狮 / 虎 / 白虎 / 豹 / 美洲豹 | 夏/秋季发情，攻击力极高，季节到即发情 |
| 熊类 | 灰熊 / 棕熊 / 黑熊 / 北极熊 | 大型杂食掠食者，夏/冬季发情，无需喂食 |
| 骑乘动物 | 马(5变种) / 驴 / 骆驼 / 驯鹿 / 鸵鸟 / 鹤鸵 | **繁殖期/幼崽期禁止上鞍骑乘** |
| 家畜 | 母牛(3色) / 公牛(4色) / 羊驼(3变种) | Cow↔Bull 互通交配，按权重生幼崽 |
| 野生草食 | 角马 / 野牛 / 驼鹿 / 犀牛 / 长颈鹿 / 斑马 / 野猪 | 群居或独居，无需喂食 |

**核心机制**：
- 公体发情时主动寻找母体，相处达阈值后交配
- 多公追同一母时互相攻击（竞争）
- 母体孕期倒计时，分娩后进入虚弱期
- 幼崽期 → 成年，体型随成长度线性增长
- 公体通常比母体大且攻击力更高
- **条件性繁衍（14 种家畜/骑乘动物/原版生物）**：需玩家在繁殖季节内**喂食特定物品**后才发情；**其余 25 种掠食者/野生草食无需喂食**，季节到即发情

> **条件性繁衍（喂食发情）**：仅对马/牛/驴/骆驼/驯鹿/鸵鸟/羊驼/角马/野牛等 14 种生物开启。到季节的生物头顶显示`需喂食`，玩家把对应食物（牛马吃高草、鸵鸟吃南瓜）扔到地上被它吃掉后进入`发情中`，持续 600 秒可交配。灰狼/熊/狮子/豹子/犀牛等 25 种**无需喂食**，季节到即自动发情。详见 [CONFIG.md "条件性繁衍参数"](CONFIG.md)。

> **交互拦截**：可骑乘物种（马/驴/骆驼/驯鹿/鸵鸟）在繁殖期（发情/怀孕/虚弱）和幼崽期**禁止上鞍和骑乘**，按物种独立配置。详见 [CONFIG.md "交互拦截参数"](CONFIG.md)。

> **第三方模组接入**：本模组支持多源配置合并，其他模组只需在自己 `MOD/Assets/` 下放一份 `BreedingConfig.{ModId}.json` 即可追加新物种的繁殖配置，无需改本模组代码。详见 [CONFIG.md "九、第三方模组接入"](CONFIG.md)。

> **配置文档**：所有可调参数详见 [CONFIG.md](CONFIG.md)。

## 一、玩法总览

灰狼在**冬季**进入发情期（无需喂食，季节到即自动发情）。发情的公狼会**主动寻找**附近的发情母狼并走过去。当公母狼在 2 格内**持续相处 10 秒**后触发交配，母狼进入孕期（1.5 游戏天 = 1800 秒），**公狼**进入虚弱期（0.75 天，不再发情，防止一公多母）。孕期结束后母狼分娩产下幼狼，**母狼**进入虚弱期。幼狼经 4.5 个游戏天成长后进阶成年，体型从最初的一半逐步长大到成年尺寸（公狼比母狼更大）。

当**多只公狼追求同一只母狼**时，公狼之间会产生矛盾，互相攻击，胜者获得交配权。

### 核心循环

```
冬季(发情) → 公狼寻路走向母狼 → 相处10秒 → 交配
                ↓                          ↓
     多公追同一母狼 → 互相攻击      母狼怀孕30秒(可见)
                                    ↓
                              分娩幼崽 → 母狼虚弱60秒(不发情)
                                    ↓
                              幼崽成长3天 → 成年(可再次繁殖)
```

## 二、繁殖机制详解

### 1. 发情期 (Estrus)

- **触发季节**：冬季 (Winter)，由配置文件 `BreedingSeasons` 决定。
- **判定条件**：当前季节在繁殖季节列表内 **且** 不在虚弱期 **且**（若开启条件性繁衍）已被玩家喂食 → `发情中`。
- **条件性繁衍（喂食发情）**：14 种家畜/骑乘物种开启了 `RequireFeeding`。到季节但未被喂食时显示`需喂食`，玩家把 `FeedItem` 指定的食物扔到地上被它吃掉后，进入`发情中`，持续 `FedDurationSeconds`（默认 600 秒）。到期后需再次喂食。其余 25 种（灰狼/熊/猫科/野生草食等）`RequireFeeding=false`，季节到即自动发情。
- **发情效果**：
  - 公狼发情 → 主动寻找母狼（寻路走向她）。
  - 母狼发情 → 等待公狼靠近，相处计时。
  - 发情期间仇恨范围 ×2（更主动追击玩家/目标）。
- **虚弱期**：交配或分娩后进入，持续 60 秒。虚弱期间**不处于发情**，不会交配或寻路。

### 2. 公狼寻路与竞争

发情的成年公狼（非虚弱）会每帧执行以下逻辑：
1. 在 `SeekRadius`（20 格）内搜索最近的**发情、成年、未怀孕、非虚弱**母狼，记录目标。
2. 检查是否有**其他公狼也以同一母狼为目标**（竞争对手）。
3. **有竞争对手** → 通过 `ComponentChaseBehavior.Attack` 攻击对方，公狼之间互相打斗，胜者获得交配权。
4. **无竞争对手** → 设路径走向母狼，直到进入 `MateRadius`（2 格）内。

> 竞争机制：当多只公狼追求同一母狼时，它们会互相攻击（追击 30 秒）。这模拟了自然界中公狼为争夺配偶而打斗的行为。败者逃离或死亡后，胜者才能继续追求母狼。

### 3. 交配条件

需**同时满足**以下全部条件，交配才会发生：

| 条件 | 说明 |
|------|------|
| 母狼处于发情期 | 冬季 且 非虚弱 且 已喂食（若开启条件性繁衍） |
| 母狼为成年 | 自然生成的狼默认成年 |
| 母狼未怀孕 | 孕期倒计时期间不会再次交配 |
| 附近有成年公狼 | 半径 2 格内（`MateRadius`） |
| 公狼同模板 | 必须同为 `Wolf_Gray` |
| 公狼处于发情期 | 公狼也需在冬季且非虚弱且已喂食 |
| **持续相处 10 秒** | 公母在 2 格内连续相处 `MatingRequiredProximitySeconds` 秒 |

> 若公狼离开 2 格范围，相处计时归零，下次需重新累计。

交配成功后：
- 母狼进入孕期（`PregnancyRemainingSeconds = GestationSeconds`），**不进入虚弱期**（怀孕期间可见孕期倒计时）。
- **只有公狼进入虚弱期**（`WeaknessRemainingSeconds = WeaknessSeconds`），立即设 `IsInEstrus=false`，防止同帧与其他母狼再次交配。
- 相处计时归零。

### 4. 孕期与分娩

- **孕期时长**：30 秒（现实秒，可配置 `GestationSeconds`）。
- **倒计时**：每帧用真实时间 `dt` 递减。
- **孕期行为**：怀孕母狼不产生仇恨（ChaseRange=0），不会再次交配。
- **分娩**：倒计时归零时，在母狼附近 1.5 格范围内生成 1 只幼狼。
- **幼狼模板**：使用母狼模板生成（保证外观一致），性别随机（50% 公 / 50% 母）。
- **分娩后**：母狼进入虚弱期（`WeaknessSeconds`），虚弱期间不发情。

### 5. 虚弱期

虚弱期是交配/分娩后的恢复阶段，防止同一只狼立即再次繁殖：

| 触发事件 | 谁进入虚弱 | 持续时间 | 说明 |
|---------|-----------|---------|------|
| 交配成功 | **公狼**（仅公狼） | 60 秒 | 母狼不虚弱，直接进入孕期 |
| 分娩完成 | **母狼** | 60 秒 | 分娩后恢复期 |

虚弱期效果：
- **不处于发情**：即使仍在冬季，也不会交配或寻路。
- **虚弱期结束**后，若仍在繁殖季节，自动恢复发情状态。
- **防止一公多母**：公狼交配后立即虚弱且 `IsInEstrus=false`，同帧内其他母狼无法找到他交配。

### 6. 幼崽成长

- **幼崽期时长**：3 个游戏天（`CubDurationDays`，按 `SubsystemTimeOfDay.Day` 计算）。
- **成长进度**：0 → 1 线性增长。
  - `成长进度 = (当前天数 - 出生天数) / 幼崽期天数`，限制在 0~1。
  - 成年后恒为 1。
- **进阶成年**：年龄达到 3 天时，幼崽期 → 成年期，立即应用成年体型。
- **幼崽仇恨**：幼崽不产生仇恨（ChaseRange=0），不会攻击玩家。

### 7. 体型动态变化

体型同时调整**碰撞盒 (BoxSize)** 和**视觉模型 (ModelScale)**，随成长进度线性插值：

```
scale = CubBoxScale + (成年scale - CubBoxScale) × 成长进度
```

| 阶段 | 公狼 | 母狼 |
|------|------|------|
| 出生（进度 0） | 0.5× | 0.5× |
| 成年（进度 1） | 1.3× | 1.0× |

- 出生时所有幼狼都是 0.5× 原版尺寸。
- 成长过程中，公狼体型增长到 1.3×（比原版大 30%），母狼增长到 1.0×（与原版一致）。
- 体型更新做了节流处理（每 60 帧刷新一次），避免每帧写入造成性能开销。

### 8. 攻击力差异

攻击力按成长阶段和性别双重乘算：

```
最终攻击力 = 基础攻击力 × 阶段系数 × 性别系数
```

| 阶段 | 阶段系数 | 性别 | 性别系数 |
|------|---------|------|---------|
| 幼崽 | ×0.3 | 公 | ×1.3 |
| 成年 | ×1.0 | 母 | ×1.0 |

**示例**：
- 成年公狼：基础 × 1.0 × 1.3 = **1.3×**（最强）
- 成年母狼：基础 × 1.0 × 1.0 = **1.0×**
- 幼狼（无论性别）：基础 × 0.3 × (1.0 或 1.3) = **0.3× 或 0.39×**（最弱）

### 9. 仇恨机制

| 状态 | 仇恨行为 |
|------|---------|
| 幼崽（公/母） | **不产生仇恨**（ChaseRange=0，不会追击玩家） |
| 怀孕母狼 | **不产生仇恨**（ChaseRange=0） |
| 成年公狼 | 正常攻击玩家；发情期仇恨范围 ×2 |
| 成年母狼（非怀孕） | 正常攻击；发情期仇恨范围 ×2 |
| 虚弱期 | 无额外效果（仇恨正常，但不发情） |

## 三、头顶浮动文字

每只被繁殖系统追踪的生物头顶会显示 3 行浮动文字(第3行包含百分比 + 图形进度条)：

```
♂公 灰狼                    ← 第1行：性别 + 生物名
成年期 | 发情中               ← 第2行：成长阶段 + 繁殖状态
成长 60% [████████░░░]       ← 第3行：成长进度百分比 + 右侧图形进度条(同一行)
```

> - 第 3 行进度条用 `FlatBatch3D` 在视图空间直接绘制(与百分比文字**同一行**，紧贴文字右侧)：背景灰半透明矩形 + 前景绿色按进度填充 + **固定白色边框**(4 条线，不随进度变化)。不依赖字符渲染，效果稳定无字体适配问题。进度条加长(宽 100 / 高 9 像素)，并加 Z 偏置避免被生物自身模型遮挡，远距离更易看清。文字+进度条整体水平居中(通过 `BitmapFont.MeasureText` 测量文字宽度计算总宽度)。
> - 所有显示文字均走**国际化**，根据游戏当前语言自动切换。翻译文件位于 `MOD/Assets/Lang/`，目前提供 `zh-CN.json`(简体中文)。其他语言欢迎贡献翻译，只需添加对应的 `xx-XX.json` 文件即可。

### 第 2 行 — 繁殖状态详解

| 繁殖状态 | 含义 |
|---------|------|
| `成长中` | 幼崽正在成长，未到发情季节 |
| `需喂食` | 成年且在繁殖季节，但未被玩家喂食（条件性繁衍开启时） |
| `发情中` | 成年且在冬季且已喂食，可交配 |
| `发情中(相处N秒)` | 母狼附近有公狼，正在累计相处时间（N/10 秒） |
| `怀孕中(N秒)` | 母狼怀孕中，N 为剩余秒数 |
| `虚弱中(N秒)` | 交配/分娩后恢复中，N 为剩余秒数，期间不发情 |
| `未在季` | 成年但不在繁殖季节 |

> 浮动文字在 16 格内全显，19 格外淡出隐藏；狼死亡后（尸体状态）不再显示。

## 四、配置文件

所有参数在 [MOD/Assets/BreedingConfig.json](MOD/Assets/BreedingConfig.json)，**退出世界重进即生效**，无需重新编译。

> 完整参数说明详见 [CONFIG.md](CONFIG.md)。

### 配置结构

全局只保留 `Enabled` 总开关，**其余所有参数都按物种独立配置**，这样不同生物可以有不同的孕期、体型、攻击力等。

```json
{
  "Enabled": true,
  "Species": {
    "Wolf_Gray": {
      "BreedingSeasons": [ "Winter" ],
      "CubDurationDays": 3,
      "GestationSeconds": 30.0,
      "AdultMaleBoxScale": 1.3,
      "MaleAttackBonus": 1.3,
      ...
    },
    "Horse_White": {
      "BreedingSeasons": [ "Spring" ],
      "CubDurationDays": 5,
      "GestationSeconds": 60.0,
      "AdultMaleBoxScale": 1.1,
      "MaleAttackBonus": 1.2,
      ...
    }
  }
}
```

> 模组开箱支持 39 个物种（14 种需喂食 + 25 种无需喂食），完整生物清单与参数对比详见 [SPECIES.md](SPECIES.md) 生物图鉴，参数含义详见 [CONFIG.md](CONFIG.md)。

### 物种参数速览（写在 `Wolf_Gray` 下）

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `BreedingSeasons` | `["Winter"]` | 繁殖季节：`Summer` / `Autumn` / `Winter` / `Spring` |
| `CubDurationDays` | `3` | 幼崽期天数（游戏天） |
| `GestationSeconds` | `30.0` | 孕期持续秒数（现实秒） |
| `MatingRequiredProximitySeconds` | `10.0` | 交配所需相处时间（现实秒） |
| `WeaknessSeconds` | `60.0` | 虚弱期持续秒数（现实秒） |
| `RivalChaseTime` | `30.0` | 公狼竞争追击时长（现实秒） |
| `MateRadius` | `2.0` | 交配判定半径（方块） |
| `SeekRadius` | `20.0` | 公狼寻找母狼的搜索半径（方块） |
| `BirthSpawnOffset` | `1.5` | 分娩幼崽偏移范围（方块） |
| `CubAttackFactor` | `0.3` | 幼崽攻击力系数 |
| `AdultAttackFactor` | `1.0` | 成年攻击力系数 |
| `MaleAttackBonus` | `1.3` | 公狼攻击力额外倍率 |
| `CubBoxScale` | `0.5` | 幼崽出生时体型缩放 |
| `AdultMaleBoxScale` | `1.3` | 成年公狼体型缩放 |
| `AdultFemaleBoxScale` | `1.0` | 成年母狼体型缩放 |
| `EstrusChaseRangeMultiplier` | `2.0` | 发情期仇恨范围倍率 |
| `CubMaleProbability` | `0.5` | 公狼生成概率（0~1） |
| `RequireFeeding` | `false` | 条件性繁衍：是否需喂食才发情 |
| `FeedItem` | `null` | 喂食物品（方块类名），留空=接受任何它原版会吃的食物 |
| `FedDurationSeconds` | `600` | 已喂食状态持续秒数（现实秒） |

> 添加新物种只需在 `Species` 下添加对应模板名条目，代码无需改动。每个物种可以只写需要修改的参数，未写的会用默认值。

## 五、测试步骤

### 灰狼测试

1. **进入世界**：创造模式，确保季节变化开启。
2. **调至冬季**：将季节调至冬季（发情期）。
3. **刷狼**：用刷怪蛋刷 4~6 只灰狼（`Wolf_Gray`），确保公母都有。
4. **自动发情**：灰狼已关闭喂食（`RequireFeeding=false`），冬季到即自动发情，头顶显示`发情中`，无需喂食。
5. **观察寻路**：公狼头顶显示`发情中`，会主动走向母狼。
6. **观察相处**：公母狼在 2 格内时，母狼头顶显示`发情中(相处N秒)`，N 逐步增加。
7. **交配**：相处达 10 秒后，日志出现 `[Breeding] 交配成功`，**公狼**头顶变为`虚弱中(900秒)`，**母狼**头顶显示`怀孕中(1800秒)`（1.5 游戏天，可见孕期）。
8. **验证一公一母**：确认同一公狼不会同时让多只母狼怀孕（公狼交配后立即虚弱）。
9. **分娩**：1800 秒（1.5 游戏天）后母狼身边生成幼狼，日志出现 `[Breeding] 分娩成功`，母狼头顶变为`虚弱中(900秒)`。
10. **成长**：幼狼头顶显示`幼崽期 | 成长中`和进度条，**体型随天数逐渐变大**。
11. **成年**：4.5 个游戏天后，幼狼头顶变为`成年期`，体型到达成年尺寸（公 1.3× 大，母 1.0×）。
12. **公狼竞争**：刷 3 只公狼 + 1 只母狼，冬季到后观察公狼互相攻击，胜者追求母狼。

### 马的测试

1. **调至春季**：将季节调至春季（马的发情期）。
2. **刷马**：用刷怪蛋刷 4~6 只同变种马（例如 `Horse_White`），确保公母都有。
3. **喂食发情**：马头顶显示`需喂食`，把**高草**（`TallGrassBlock`）扔到马附近，马吃掉后头顶变为`发情中`。
4. **观察寻路**：公马头顶显示`发情中`，会主动走向母马（半径 24 格）。
5. **交配**：公母马在 2.5 格内相处 12 秒后交配，公马进入虚弱期（1200 秒），母马怀孕（2400 秒 = 2 游戏天）。
6. **分娩**：2400 秒（2 游戏天）后母马身边生成**同变种**马驹（白马生白马），母马进入虚弱期。
7. **成长**：马驹头顶显示`幼崽期 | 成长中`，6 个游戏天后进阶成年，公马体型 1.1×、母马 1.0×。
8. **变种隔离**：刷 2 只 `Horse_White` + 2 只 `Horse_Black`，观察白马只和白马交配，不会跨变种混血。
9. **公马竞争**：刷 3 只同变种公马 + 1 只母马，喂食后观察公马互相攻击，胜者获得交配权。

> **快速测试**：想在任意季节快速验证马的繁殖，可参考 [CONFIG.md](CONFIG.md) "七、常见调参场景 → 4. 加快马的测试速度"，把所有马变种的 `BreedingSeasons` 改为四季、`GestationSeconds` 改为 15 秒。

## 八、技术说明

### 运行时数据流

```
OnEntityAdd          → 注册新个体(成年/随机性别) → 缓存原版BoxSize+ModelScale → 应用体型
OnFactorsUpdate(每帧) → 虚弱倒计时 → 喂食状态倒计时 → 发情判定(季节+非虚弱+已喂食) → 成长推进 → 体型更新 → 仇恨Factor → 性别更新
                       母狼: 孕期倒计时/相处交配
                       公狼: 寻路走向母狼 / 竞争对手互相攻击
OnEatPickable        → 生物吃掉落物 → 匹配FeedItem → 标记"已喂食"(FedDurationSeconds秒)
OnMinerHit           → 攻击力修正(阶段×性别)
OnSaveSpawnData      → 状态序列化为 JSON 存档
OnReadSpawnData      → 读档恢复状态
OnModelRendererDrawExtra → 头顶浮动文字渲染
```

### 关键设计决策

- **体型修复**：同时设置 `ComponentBody.BoxSize`（碰撞盒）和 `ComponentModel.ModelScale`（视觉模型），确保幼崽体型在视觉和物理上同步变化。
- **公狼寻路**：通过 `ComponentPathfinding.SetDestination` 设路径走向母狼。若追击行为（ComponentChaseBehavior）激活则追击优先。
- **公狼竞争**：每只公狼记录 `TargetFemaleId`，当两只公狼目标相同时，通过 `ComponentChaseBehavior.Attack` 互相攻击，模拟自然界争夺配偶。
- **相处计时**：放在母狼侧。每帧检查 MateRadius 内有无发情公狼，有则累加，无则归零。达阈值后触发交配。
- **虚弱期**：交配后仅公狼虚弱（母狼直接怀孕，孕期可见），分娩后母狼虚弱。虚弱期间 `IsInEstrus=false`，阻止交配和寻路。
- **防止一公多母**：公狼交配后立即设 `IsInEstrus=false` + `WeaknessRemainingSeconds`，同帧内其他母狼的 `FindNearbyEstrusMale` 找不到他（双重保险：`IsWeak` 检查 + `IsInEstrus` 检查）。
- **仇恨控制**：通过 `ComponentFactors.OtherFactors["ChaseRange"]` 添加 factor。值为 0 且 Multiply 类型 → 仇恨范围归零。
- **状态持久化**：通过 `SpawnEntityData.Data`（JSON）随实体存档。`OriginalBoxSize`/`OriginalModelScale`/`IsInEstrus`/`IsWeak`/`TargetFemaleId` 标记 `[JsonIgnore]`，加载时重新缓存或每帧重算。
- **确定性性别分配（防退出重进性别变化）**：性别恢复遵循"缓存优先"（`BreedingModStates`/`SpawnEntityData.Data`/`BreedingStates.xml` 三层缓存），缓存缺失时的兜底不再用 `Random` 随机掷，而是用 **EntityId 的稳定哈希** 计算。SC 中 EntityId 跨 Despawn/Respawn（存于 `SpawnEntityData.EntityId`）与存档重载（存于 `Project.xml Entities/@Id`）保持不变，因此同一只生物无论缓存是否命中、命中哪一层，性别永远一致；统计上仍按 `CubMaleProbability` 分布。
